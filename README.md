# StarArm 102-HD + B601-RS 固定空载阻尼遥操作

这是独立项目，使用 `stararm_rs_damping` 包和 **8767** 端口，配置及运行状态保存在本目录 `data/web/`。原力反馈项目的源码、服务、配置和 Python 安装保持不变。

## 启动网页

```bash
cd /home/vincent/Documents/Codex/2026-11-13/stararm-rs-unloaded-damping
bash run_dashboard.sh
```

打开 <http://127.0.0.1:8767/>。脚本默认使用 `~/miniforge3/envs/lerobot/bin/python`，无需在 base 环境安装依赖。其他机器可设置 `STARARM_PYTHON=/你的环境/bin/python`。只启动网页不会连接或移动机械臂；在页面点“启动遥操作”后才使用现有 LeRobot 插件连接设备。

默认设备为 RS 从臂 `can0`、StarArm 102-HD 主臂 `/dev/ttyUSB0`、30 Hz，沿用现有 `follower1` 和 `rebot_arm_102_leader` 校准。启动前需要 CAN 已开启且为 1 Mbps。不自动更改 CAN、零点、校准或电机参数。

## 固定空载阻尼

- 根据用户提供的 `fs102hd_damping.py` 集成 **opcode `0x09`** 指令，所有七轴默认 **100 mW**，包括脚本原先未列出的 ID 2（J3）。
- 网页可开启/关闭固定阻尼，并设置 J1–J7 各轴 **0–1500 mW**。0 表示发解锁指令，不把特殊含义的零功率发给阻尼指令。
- 普通阻尼与从臂负载、扭矩、姿态无关；不计算重力残差，不按负载改变功率，也不触发旧版的整臂堵转 HOLD。
- 关闭固定阻尼后，遥操作继续，夹爪锁仍由独立开关控制。保存后以“已应用 vN”确认控制循环接收。
- 从臂使用官方原有夹爪跟随控制，不包含降低到 `kd=0.3` 的振荡方案或快档切换。

## 夹爪软件锁

保留原网页的接触 HOLD、保持功率、接触/释放扭矩、确认时间及反向解锁设置。启用时：

1. J7 无接触时 FREE，夹住物体并确认后仅 J7 HOLD。
2. 继续合拢受到限制；轻微反向张开或确认失去夹持接触后释放。
3. J7 锁优先于固定阻尼。锁启用时，J7 未接触及释放后都 FREE；关闭锁后才恢复 J7 的固定阻尼设定。

这个功能仍使用从臂实际电机扭矩及运动判断接触，属于独立的夹爪接触反馈；“无力反馈”指移除了七轴按负载变化的普通力反馈。软件 HOLD 有功率限制并且双向保持，不是机械单向锁。首次初始化已复制原项目当前的夹爪锁调参值，其后各自独立保存。

## SDK 与项目隔离

原脚本 `0x09` 与旧版 `set_stop_mode(..., mode=0x12)` 的协议不同。新项目在 `vendor/` 内提供私有 Smart Servo SDK，增加 `set_damping()` 并沿用控制器原生互斥锁，复用 Leader 已有串口；不会另外运行参考脚本或打开第二个串口。仅新遥操作子进程将 `vendor/runtime` 加到导入路径，不执行 `pip install` 替换共用环境。构建说明见 [vendor/README.md](vendor/README.md)。

两个网页可以同时打开，但同一套机械臂只能由一个遥操作会话控制。新项目复用原有设备互斥锁；先在旧网页正常停止会话，再到新网页启动。CAN 过期、故障、过温及 Leader 连续缺帧仍中断会话。停止相当于正常 Ctrl+C，官方退出流程可能回零或卸力，应按原来的方式支撑机械臂。

网页显示实际 RS 姿态、扭矩、电流，Leader 模式与请求功率、可靠电流/功率读回，以及夹爪锁状态。请求功率不是实测夹持力。页面断线不能确认机械臂已停止，应检查实际会话和设备。

不录制运动 CSV；仅在本项目 `data/web/` 保存网页设置、最新状态和必要的会话诊断文字日志。
